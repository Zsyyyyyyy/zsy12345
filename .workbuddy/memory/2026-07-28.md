# 2026-07-28

## 统一全站字体
- 7 个 HTML 页面（index/timestamp/hash/currency-converter/tetris/fortune/zhconvert）统一字体为 `Maple Mono, Maple Mono CN, 霞鹜文楷等宽, LXGW WenKai Mono, monospace`
- 实现方式：在每个文件 `<style>` 顶部注入全局规则 `*, *::before, *::after { font-family: ... !important; }`
- 使用 `!important` 是因为各页面有大量显式 `font-family` 声明（如 `"SF Mono","Monaco",monospace`），不加会被覆盖
- 仅引用本地字体名，未加 CDN（霞鹜文楷等宽无官方 CDN mono 包；用户本地已安装）
- CDN 验证：`@fontsource/maple-mono`（latin）可用；`lxgw-wenkai-screen-webfont` 可用但非严格等宽
