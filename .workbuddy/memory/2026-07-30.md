# 2026-07-30

## 笔记本重构成论坛风格
- 用户反馈原笔记「查看起来太小」，要求仿照论坛样式
- 重写 `notes.html`：从小卡片 + 弹窗查看 改为 论坛版块式列表 + 独立阅读页
- **列表（版块）**：帖子一行行排开（底部分隔线），左侧编号 #NN，标题 16px + 单行预览 + 信息栏（分类徽章/时间/字数），右侧日期+箭头；顶部加搜索框、分类当版块
- **阅读页（帖子）**：点帖进入整页阅读，标题 24px、正文 16px/行距1.9、`white-space:pre-wrap` 保留换行，meta 行显示发布/更新时间+字数，底部编辑/删除按钮
- 编辑仍用弹窗（放大到 640px、textarea 220px），新建叫「新帖/发布」
- 新增：实时搜索（防抖 200ms）、Esc 返回列表、阅读页内编辑后原地刷新
- 数据仍是 localStorage `zsy_notes`，原有笔记不受影响；功能/快捷键全部保留

## 笔记本加密码锁
- 新增终端风格密码锁界面（全屏 overlay，z-index 500）
- 逻辑：首次打开（`zsy_notes_lock` 未配置）→ 引导设置密码（可"暂不设置"跳过，写入 'off'）；已设密码（存哈希）→ 每次打开弹解锁界面
- 密码用纯 JS 实现的 SHA-256 哈希后存 localStorage（不存明文），UTF-8 编码兼容中文密码；不用 crypto.subtle（file:// 非安全上下文可能不可用）
- 解锁错误有抖动动画 + `zsh: 密码错误` 提示；Enter 提交
- header 加 🔒/🔓 按钮，弹"密码保护"设置 modal：可启用/修改（需当前密码）/取消保护/立即锁定
- 立即锁定后回到列表并重新上锁；未解锁时屏蔽所有笔记操作与快捷键（unlocked 守卫）
- 注意：纯前端锁定，内容仍在 localStorage 明文，仅防随意翻看，非真正加密
