## 关键架构修正：去掉后端，改纯静态（SSG 思路）
- 问题：用户把代码部署到了服务器，但 server.js 是 Node 后端，静态托管/静态服务器不会运行它 → /api/notes 永远 404，页面报「无法读取笔记数据」；本地后台起的 node 进程也总被回收
- 解决：新增 `build-notes.js`，把 notes/**/*.md 扫描打包成静态 `notes-data.js`（`window.NOTES_DATA = [...]`，含 region/标题/时间/内容）
- notes.html 改为 `<script src="notes-data.js">` 读取 window.NOTES_DATA，删掉 fetch('/api/notes')；script 标签加载本地文件在 file:// 和任何静态托管都可用（file:// 只限制 fetch，不限制 script src）
- 删除 `server.js`（纯静态后不再需要后端）
- **新工作流**：编辑 notes/ 下的 .md → 本地跑 `node build-notes.js` 重新生成 notes-data.js → git 提交（notes-data.js 也要提交）→ 部署即生效；本地直接双击 notes.html 也能看
- 已验证：build 出 4 篇（台湾/回复、易利委回复、商品备注 + 欢迎使用.md），用户删掉了四个地区模板笔记和 1.md，在真实使用台湾相关笔记
