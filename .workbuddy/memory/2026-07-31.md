# 2026-07-31

## 新增店铺价格计算器 (price-calc.html)
- 创建 `price-calc.html`：仿 Shopee 官方「定价模拟器」的终端风格版本
- 公式：`店铺价格 = ((全球价 × 汇率 × 调价比例) + 物流成本) ÷ (1 − 佣金% − 交易手续费% − 活动服务费%)`
- 支持三市场：台湾(汇率4.8,佣金14%)、泰国(汇率4.95,佣金22.47%)、越南(汇率3900,佣金18%)
- 左右两栏布局：左侧输入（商品成本价、预期净利润、折扣、包裹重量、调价比例、各项费率），右侧实时结果
- 结果包含：折前售价 / 折后售价 / 净利润率 / 订单收入 / 调价比例
- 费用明细可折叠拆解：平台费用(佣金+交易手续费+活动服务费)、物流费用(跨境物流+买家付运费)、其他费用(提现手续费)
- 每项金额同时显示本地币(TWD/฿/₫)和换算 CNY
- 调价比例改为百分比输入(默认150%=1.5倍)
- 终端风格，与全站统一；参数框两列网格紧凑排列，一屏内可见全部信息
- 将定价模拟器合并到 `currency-converter.html`，左右 50/50 布局：左侧货币转换器（原功能不变），右侧定价模拟器（含公式推导实时显示）
- 独立的 `price-calc.html` 仍保留

## 定价模拟器新增第二种计算模式（售价→利润）
- 顶部新增模式切换：① 成本→售价（原反推，输入成本+目标净利润）、② 售价→利润（新模式，输入预期售价本地币，正推净利润+净利润率）。用户选「仅净利润+利润率」，故模式②突出净利润+利润率，费用明细组保留作支撑。
- 实现：`var mode` + `setMode(m)` 切换；②输入框在「预期净利润」(fldTarget) 与「预期售价」(fldExp) 间显隐；render() 内 priceAfterDisc 来源按 mode 分支；结果列表与右侧公式推导均按 mode 分支；expPrice 默认值 262 并加入 input 实时监听列表。
