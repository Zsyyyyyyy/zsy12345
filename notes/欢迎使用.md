# 欢迎使用 Markdown 笔记本

这是一个**只读**的 Markdown 笔记本。笔记就是这个目录下的 `.md` 文件，用任何编辑器写，浏览器只负责展示。

## 怎么用

1. 在 `notes/` 目录里新建一个 `.md` 文件，比如 `读书笔记.md`
2. 用编辑器（VS Code / vim / 记事本）写内容，保存
3. 刷新这个页面，新笔记就出现了

## 支持 Markdown 语法

- **加粗**、*斜体*、`行内代码`
- 列表、引用、链接、表格

```js
// 代码块也支持
console.log("hello, notes");
```

> 文件的第一行 `# 标题` 会作为列表里显示的标题；没有标题就用文件名。

> 文件在 git 仓库里，改完可以 `git add notes/ && git commit` 做版本管理。
